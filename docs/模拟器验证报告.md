## 结论

当前 Debug 版本已经完成以下主链路：

- 外部系统文件选择器打开 `content://` 文件。
- SAF 目录/项目授权、目录列表和文件打开。
- 应用私有项目目录浏览。
- ZIP 导入、单根目录折叠、条目数量/总大小限制和路径穿越拦截。
- 公共 HTTPS Git 仓库浅克隆；克隆弹框统一使用应用配色、仓库地址示例和 HTTPS 地址校验。
- 默认只读的 Sora Editor 阅读界面。
- 本地文件和 SAF 文件编辑、保存。
- 源码编辑模式支持撤销、重做并实时反馈可用状态；标签草稿撤销回已保存正文时会恢复为“已保存”。
- 文件内搜索栏支持替换当前、全部替换和正则捕获组替换；当前替换会重新核对精确行列，全部替换一次即可撤销。
- 独立“编辑器”设置页支持 2/4/8 Tab 宽度、空格/Tab 缩进、自动缩进、括号与引号补全和多行粘贴缩进优化，修改后无需重新打开当前标签。
- 阅读工具栏通过单一“编辑操作”入口提供选中当前行、删除行、复制、剪切、粘贴、缩进和反缩进；只读源码只开放选中与复制，修改操作明确禁用。
- 未保存草稿按文档写入 Android 明确排除备份的 `noBackupFilesDir` 下的应用私有 `AtomicFile`，进程重建并重新打开文件后可恢复；保存、撤销回原文或明确放弃标签时自动清理。
- 草稿恢复会校验来源、编码和原正文指纹；磁盘文件已变化时先显示冲突选择，用户明确选择后才会恢复旧草稿。
- 本地文件保存改为同目录临时文件、`fsync` 和原子重命名；SAF 保存前备份原始字节，写入失败会自动回滚，回滚也失败时明确提示原文件可能受影响。
- 不可写来源和分段大文件在阅读页“更多”菜单提供“导出原文件副本”；导出重新读取完整 Local/SAF 原始字节，保留编码、BOM、换行与大文件尾部，显示进度并支持取消，失败或取消时尝试删除系统新建的半成品。
- 可折叠的项目树，嵌套目录和文件使用完整路径索引。
- 文件内搜索、项目全局搜索、按路径过滤的快速文件切换；全局搜索支持键盘提交、加载/失败/空状态、快速清除和命中高亮。
- Git 地址输入框固定显示 5 行，长地址可完整换行查看；克隆过程显示当前阶段、确定或不确定进度并支持取消，项目目录使用仓库名称。
- 已克隆仓库在项目标题栏提供“获取最新代码”；先 `fetch` 并展示分支、提交、文件变化与本地修改摘要，只有工作区干净且分支、上游、HEAD 和目标提交均未变化时才应用精确 fast-forward-only 更新，成功后重建完整目录索引。
- 首页稳定显示“最近打开”菜单，独立页集中管理最多 6 个可恢复项目，支持 SAF URI 和应用私有目录。
- 多文件标签页，每个标签页独立保留草稿、编辑状态和 Markdown 预览状态；最多缓存 4 个按文档隔离的 Markdown WebView，源码与预览按语义块同步阅读位置。
- 首页、设置、项目和阅读页统一使用 56dp 紧凑标题栏，同时保留 48dp 图标触控区域；首页常用文件/项目入口与低频 ZIP/Git 导入形成 76dp/64dp 层级，示例改为无填充列表，阅读页继续使用紧凑上下文工具栏。
- 项目搜索进入专注模式后收起无关标题栏操作，结果按文件名、父路径、行号和摘要分层展示；目录树限制深层视觉缩进并向 TalkBack 暴露完整路径和展开状态。
- 文件内搜索原位替换上下文工具栏，关闭后恢复文件切换、Markdown 模式和编辑操作，正文高度不会重复跳变。
- TextMate 语法高亮，按文件类型加载独立 grammar。
- 首页右上角提供齿轮设置入口；一级设置页按“阅读与显示 / 编辑器 / 应用外观 / 关于与更新”分类，点击后进入对应二级页。
- 系统侧边返回手势、系统返回键和硬件返回键使用同一返回栈：设置二级页先回一级设置，一级设置再回首页；首页再次返回会显示退出确认。
- “阅读与显示”和“应用外观”二级页保留固定实时预览；显示设置覆盖 11-24 sp 字号、跟随主题/柔和灰/护眼绿/暖纸色阅读背景，以及翡翠绿/海洋蓝/琥珀金整体配色，选项使用紧凑的下拉选择器。
- 设置页提供在线更新入口，可从公开 GitHub Latest Release 检查新版本；弹框按更新说明、下载进度、操作按钮的顺序展示，并在校验 APK 完整性与应用身份后进入系统安装流程。
- 应用、源码和 Markdown 统一使用手机系统字体；高对比亮色和 Darcula 暗色会立即刷新当前编辑器与 Markdown 预览，字号、背景、配色、明暗模式、自动换行和编辑器输入偏好均持久化到 `SharedPreferences`。
- 首页、目录页和阅读页只应用一次状态栏安全区，标题不再出现重复顶部留白。
- Markdown 源码/预览切换，覆盖常用语法、表格、任务列表和脚注。
- YAML Front Matter 使用默认折叠的语义化区块展示，展开后按 YAML 高亮，且不会污染 Markdown 目录。
- Markdown 代码块使用 highlight.js 高亮，数学公式使用 KaTeX，流程图使用 Mermaid；全部离线渲染。
- Markdown 本地图片按当前项目相对路径离线加载，支持点击放大；相对附件点击后进入灵阅现有标签页，项目外路径会被拒绝；图片、KaTeX 和 Mermaid 单项失败时显示原始内容及源码回退。
- Markdown 目录在预览工具栏固定可达，支持展开、折叠、限高滚动和标题跳转后自动收起；代码块支持一键复制。
- Markdown 预览“更多”菜单提供渲染文本复制、HTML 导出、HTML 渲染结果分享和 PDF 系统打印/保存；HTML 使用系统文件创建器保存，分享使用受授权的 FileProvider URI，本地图片与 KaTeX WOFF2 字体会内联到单文件 HTML。
- 跳转到行和源码自动换行。
- 超过 1 MB 的文件自动进入只读分段模式，每次追加约 256K 字符。
- 竖屏和横屏布局。
- Debug 构建保留 78 个语法测试文件和内置测试项目；Release APK 已确认不包含 `assets/samples`、运行时语法覆盖器和开发验证入口。
- Release APK 仅保留 `assets/examples` 示例项目，用于离线体验 Front Matter、本地图片与附件、代码块、KaTeX 和 Mermaid。
- 新增文件弹窗支持常用源码、配置和 Markdown 类型选择；会自动补齐匹配扩展名，并写入对应的最小代码模板后打开编辑。

本轮 `testDebugUnitTest`、`lintDebug`、Debug APK、AndroidTest APK 和 Release APK 均构建成功；`Pixel_9` 上全量 instrumentation 91/91 通过，包含 Git 克隆、更新前提交/文件范围预览、工作区与未保存草稿保护、同提交分支切换和上游配置变化拒绝、精确安全快进，以及大文件流式搜索、精确行列跳转、取消/进度反馈、标签状态恢复、撤销/重做、当前/全部替换、正则捕获组和单次撤销、自动缩进、括号补全、Tab/空格缩进、行与剪贴板操作、多行粘贴优化、跨进程草稿恢复、草稿冲突选择、本地原子保存失败保护、SAF 写入回滚及回滚失败告警、不可写 SAF/大文件完整原始字节副本导出、导出取消和失败半成品清理、Markdown 高级语法和导出回归，以及新增文件类型选择、扩展名补齐、模板正文写入、默认文件名替换和空文件名反馈。当前记录不把 Redmi 真机上的旧验证结果计入验收；正式签名包和历史联网验证仍以对应版本的发布记录为准。

## 已修复问题

1. Gradle wrapper 脚本参数转义不兼容 macOS。
   - 改用 Sora Editor 仓库中由新版 Gradle 生成的 wrapper 脚本。
2. Material 3 主页按钮继承默认紫色 container。
   - 显式配置绿色、灰色和中性色 container。
3. Android assets 中的隐藏 `.env` 无法稳定枚举/打开。
   - Debug 测试资产统一使用 `environment.env`；正式版不再生成或携带 `.env` 测试数据。
4. UI 测试直接查找 LazyColumn 屏幕外的 `Program.cs`。
   - 给列表增加测试标记，滚动到目标后再点击。
5. Android 36 在应用校验前先以 `ZipException` 拦截恶意路径。
   - ZIP 导入边界统一包装错误并清理半成品目录。
6. 默认模拟器安装脚本误判 AVD 不在 adb 且非监督启动退出。
   - 使用 `--supervised` 保持可见 AVD，每次按 `ro.boot.qemu.avd_name=Pixel_9` 确认实际序列号后再显式指定；本轮最终回归序列号为 `emulator-5556`。
7. 高亮主题文件名与 TextMate 注册名不一致导致初始化失败。
   - 统一高对比亮色主题的 asset 文件名、主题模型名和持久化映射，并增加切换测试。
8. Material 3 TopAppBar 重复应用状态栏 inset，导致每个页面标题上方留白过大。
   - 首页、目录页和阅读页统一使用空的 TopAppBar windowInsets，保留 Activity 已提供的系统栏安全区。
9. Markdown 测试内容过少，代码块没有语法高亮，也无法验证公式和流程图。
   - 改用离线 WebView 预览内核，加入 Markdown-it、highlight.js、KaTeX、Mermaid 和 DOM 级设备测试。
10. 工程阅读只能逐层进入目录，缺少跨文件导航。
   - 建立统一项目索引，提供可折叠树、项目全局搜索、最近项目和快速文件切换。
11. 多文件往返时会丢失当前草稿和阅读状态。
   - 引入独立标签页状态，同时保留草稿、编辑模式和 Markdown 预览模式。
12. 超大文件依赖整体读入，容易在手机端形成明显卡顿。
   - 超过 1 MB 后改为只读分段加载，每次追加约 256K 字符，并增加设备测试。
13. SAF 嵌套目录重建 `DocumentFile` 时会回到树根。
   - 索引递归改为直接使用 `listFiles()` 返回的子节点，并在真实 DocumentsUI 授权目录上展开三层路径验证。
14. 未保存标签可直接关闭，草稿会无提示丢失。

15. Markdown 全局搜索命中会留在预览页，首次打开时还可能在 Sora 建立行索引前跳转。

26. 已克隆仓库无法获取远程最新提交。
   - 项目标题栏增加“获取最新代码”；更新仅允许 `fast-forward-only`，有未保存标签时先阻止操作，HEAD 变化后再刷新索引和关闭旧缓存标签。
27. 首页各来源入口权重接近，示例区域卡片过多，最近项目还需要二次进入才能识别目标。
   - 文件/项目保持主要入口高度，ZIP/Git 收紧为次级入口，示例改为无填充列表，并在最近打开入口直接展示最近项目名称。
28. 项目全局搜索复用页面忙碌状态，搜索期间会阻塞浏览，而且缺少键盘提交、加载失败和空结果反馈。
   - 搜索改用独立异步状态，支持键盘 Search、清除与重试；结果区明确区分加载、失败、空结果和命中数量，并高亮查询词。
29. 深层目录缩进会持续挤压文件名，搜索标题栏在窄屏中过于拥挤，目录展开状态也没有完整的无障碍说明。
   - 目录视觉缩进最多保留五层，向 TalkBack 提供完整路径和展开/折叠状态；搜索模式收起无关操作，快速文件切换条目显式保证至少 52dp 触控高度。
30. 未保存正文只存在 ViewModel 内存，进程回收后再次打开文件会丢失草稿。
   - 草稿改为按文档稳定 ID 写入独立 `AtomicFile`，增加 500ms 防抖、数量/容量治理和恢复后的自动清理。
31. 草稿生成后原文件可能被 Git 更新或其他工具修改，直接恢复会覆盖新内容。
   - 恢复前比较来源、编码和正文指纹；不一致时显示阻断式冲突弹框，由用户明确选择文件版本或草稿版本。
32. 本地文件与 SAF 直接以截断模式覆盖，写入中途失败可能破坏原文件。
   - 本地文件使用同目录临时文件、同步和原子替换；SAF 写前备份、失败回滚，并在回滚失败时升级为“原文件可能已受影响”的明确错误。
33. 编辑器输入行为使用固定默认值，用户无法按项目习惯调整缩进和补全，切换后还可能需要重新打开文件。
   - 新增独立编辑器设置页和持久化状态，将 Tab 宽度、缩进方式、自动缩进、括号补全和粘贴优化实时下发到当前 Sora 实例。
34. 常用行与剪贴板操作缺少可发现入口，直接在工具栏堆叠按钮又会挤压小屏正文。
   - 工具栏只增加一个“编辑操作”入口，统一 BottomSheet 承载七项命令；命令粘贴直接提交剪贴板正文，避免面板关闭后 IME 尚未恢复导致无反馈。
35. 不可写 SAF 和大文件只能看到“只读”，没有安全的后续修改路径；直接导出当前正文又会截断大文件并改变编码。
   - 仅在需要替代操作时显示“导出原文件副本”，从来源流式复制完整原始字节；统一进度与取消反馈，失败/取消后按 Android `ACTION_CREATE_DOCUMENT` 新文件语义清理半成品。
36. Git 更新直接执行 `pull`，用户无法在工作区变化前确认远端范围，旧预览也缺少分支和上游复核。
   - 拆分为 `fetch → 更新预览 → 用户确认 → 精确 FF_ONLY`，展示提交/文件/本地修改摘要；确认时重新核对完整分支引用、上游配置、HEAD、远端跟踪引用和目标提交，任何变化都会安全中止。

## 当前限制

- 大文件分段加载当前按字符位置从文件头重新 skip；极大文件连续加载后半部时，后续可换成可定位通道或持久流。
- 项目索引不再限制条目数量；超大工程首次建立完整目录索引会增加等待时间和内存占用。项目全局搜索会按文件编码流式扫描超过 2 MB 的文件，每个文件最多展示 8 个命中，总结果最多 200 条；文件内搜索最多保留 10,000 个精确跳转位置，但继续统计完整命中数。
- Git 支持公开 HTTPS 浅克隆、更新前提交/文件变化预览、工作区与未保存草稿保护，以及当前跟踪分支的精确安全快进；尚未实现凭据、分支/Tag/Commit 浏览、完整行级 Diff、冲突查看/处理和自动合并。
- Markdown 为保证安全默认禁用原始 HTML，远程图片不会在预览 WebView 内联网加载；本地资源只能命中当前项目索引，不能用 `../` 越过项目根。
- Markdown 预览的首次搜索和目录跳转当前使用页面加载后的短延时调度；极慢设备或超长文档上如果首次未定位，需要再触发一次。
- 当前支持预置字号、阅读背景和整体配色组合；尚未提供任意颜色值或自定义 TextMate token 配色编辑器。
- 最近项目只记录可恢复的 SAF URI 或应用私有目录；Markdown 示例、Debug 测试项目和外部单文件不进入列表。
- 在线更新只支持当前固定的公开 GitHub 仓库与正式 Latest Release；Release 必须使用 `vX.Y.Z` 标签、同名 APK、递增 `versionCode` 和同一发布证书。当前保守校验不支持发布证书轮换。
- 源码编辑已支持撤销/重做、查找替换、输入辅助、常用行与剪贴板操作、跨进程草稿恢复、本地原子保存、SAF 回滚和不可写来源/大文件完整副本导出；Sora 撤销栈不跨标签或进程保留。系统文件创建器的最终保存位置选择仍属于手工交互边界，自动化重点验证完整字节、进度、取消与失败清理。
